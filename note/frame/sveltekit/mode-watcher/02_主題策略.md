

## 絕不寫死顏色名稱（避免使用特定的色彩 Class）

    ❌ 不要寫：bg-blue-600、text-slate-900、border-gray-200
    ⭕ 應該寫：bg-primary、text-foreground、border-border



## 全站統一透過 app.css 控制 HSL 色彩變數
shadcn-svelte 預設就已經幫你在 src/app.css 設定好了 :root (亮色) 與 .dark (暗色) 的變數結構。

一開始你就擁有：

色彩架構：亮色模式 / 暗色模式
主題架構：預設主題 (Default)

## 外層 Layout 掛載 ModeWatcher
第一天就在 src/routes/+layout.svelte 放好 <ModeWatcher/>。這樣一來，系統底層就已經具備了「讀取 <html> 上面的 Class 來變色」的反應機制。

# 2. 根框架帶入系統主題 (src/routes/+layout.svelte)

```html
<script>
  import { ModeWatcher } from "mode-watcher";
  import "../app.css";

  let { data, children } = $props(); // Svelte 5 Runes

  // 假設系統主題來自後端 (例如: 'theme-emerald' 或 'theme-violet')
  // 若沒設定則預設使用空字串（吃預設藍色）
  let systemTheme = $derived(data?.systemTheme || 'theme-emerald');

  // 當系統主題改變時，自動套用到 <html> 節點上
  $effect(() => {
    if (typeof document !== 'undefined') {
      // 清除舊主題 class，並載入系統指定的新主題
      document.documentElement.classList.remove('theme-blue', 'theme-emerald', 'theme-violet');
      if (systemTheme) {
        document.documentElement.classList.add(systemTheme);
      }
    }
  });
</script>

<!-- 暗黑模式仍由 mode-watcher 獨立監聽控管 -->
<ModeWatcher />

<div class="min-h-screen bg-background text-foreground transition-colors duration-200">
  {@render children()}
</div>
```


## or 捨棄 $effect, 不操作 DOM (document.classList)
```html
<!-- src/routes/+layout.svelte -->
<script>
  import { ModeWatcher } from "mode-watcher";
  import "../app.css";

  let { data, children } = $props();

  // 系統主題 (例如 'theme-emerald')
  let systemTheme = $derived(data?.systemTheme || 'theme-emerald');
</script>

<ModeWatcher />

<!-- 關鍵：直接將系統主題 class 帶在全站最外層容器上！ -->
<div class="{systemTheme} min-h-screen bg-background text-foreground transition-colors">
  {@render children()}
</div>

```

##  or 封裝 src/lib/theme.js

```js

// src/lib/theme.js

/** 系統支援的所有主題清單 (用於批次清除) */
export const SUPPORTED_THEMES = ['theme-blue', 'theme-emerald', 'theme-violet'];

export function applySystemTheme(themeName) {
  // 防護機制：確保只在瀏覽器端 (Client-side) 執行，避免 SSR 報錯
  if (typeof document === 'undefined') return;

  const root = document.documentElement;

  // 1. 清除所有已存在的主題 Class
  SUPPORTED_THEMES.forEach((theme) => {
    root.classList.remove(theme);
  });

  // 2. 加上新的系統主題 Class（非預設值時才加入）
  if (themeName && themeName !== 'theme-blue') {
    root.classList.add(themeName);
  }
}
```



# 3. 使用者介面只留「暗黑模式切換按鈕」
因為使用者無法切換主題，所以 UI 上不需要呈現顏色選擇選單，只提供簡潔的亮色/暗黑切換按鈕：

```html
<!-- src/lib/components/DarkModeToggle.svelte -->
<script>
  import { mode, toggleMode } from 'mode-watcher';
  import { Button } from '$lib/components/ui/button';
</script>

<Button variant="ghost" size="icon" onclick={toggleMode} title="切換亮色/暗黑模式">
  {#if $mode === 'dark'}
    <span class="text-lg">🌙</span>
  {:else}
    <span class="text-lg">☀️</span>
  {/if}
</Button>
```
