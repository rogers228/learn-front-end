# 架構

# 自動雲端部屬
僅 git push 後，cloudflare 就會完成編譯與部屬

以 sveltekit 為跟目錄 然後 build時 會自動 Deploy to Cloudflare。 不需要寫 worker 的index.js


[你 Git Push 上傳程式碼]
         ↓
[Cloudflare 收到通知，自動觸發 Build]
         ↓
[Cloudflare 自動建立/更新 Pages 專案 & Worker 邊緣環境]
         ↓
[發布成功並提供網址 https://ispc-core2.pages.dev]
