# tv範例

```html
<script>
  import { tv } from "tailwind-variants";

  // 1. 【樣式與邏輯區】所有風格、尺寸、狀態、Slot 全部集中在 script
  const alert = tv({
    slots: {
      box: "p-4 rounded-lg flex items-start gap-3 border transition-all",
      title: "font-semibold text-sm",
      description: "text-xs mt-1 opacity-90",
    },
    variants: {
      intent: {
        info: { box: "bg-blue-50 border-blue-200 text-blue-900", title: "text-blue-950" },
        danger: { box: "bg-red-50 border-red-200 text-red-900", title: "text-red-950" },
      }
    },
    defaultVariants: { intent: "info" }
  });

  let { intent = "info", titleText, class: className, children } = $props();
  const { box, title, description } = alert({ intent, class: className });
</script>

<!-- 2. 【Markup 結構區】保持 100% 清爽、語意化且直觀！ -->
<div class={box()}>
  <div class="flex-1">
    <h4 class={title()}>{titleText}</h4>
    <div class={description()}>
      {@render children?.()}
    </div>
  </div>
</div>
```


# 優勢

1. Markup 閱讀體驗回歸：打開檔案一眼就能看懂 HTML/Svelte 節點結構，不再被上百個 Tailwind class 刺眼。

2. 單一真實來源，集中管理：修改 UI 樣式時，目標明確——直接進 < script > 改 tv 設定檔。

3. 無痛維護與擴充：未來不論是要增加主題顏色、微調內距，還是讓外部傳入客製化 Class，都不會破壞原本的 UI 邏輯。
