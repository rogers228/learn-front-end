# tailwind variants
tv 就是 tailwind variants(變體)

## tv 就是讓程式碼保持整潔、強健與可維護的神器！
當 component 有多種屬性，每種屬性有多種選項，例如：5個屬性與每屬性6個選項，就會有6^5=7776的可能性，直接爆炸無法維護。
以及typescript自動推導型別。

## 檢查
```
"tailwind-variants": "^3.3.1",
```

## 如果用 tv：
你不需要去窮舉這 7,776 種組合！你只需要像寫 對照表（Lookup Table） 一樣，把 5 個屬性（Key）、每個屬性的 6 個選項（Value）各自定義好，cva 就會利用矩陣查表的方式，在運行時（Runtime）自動為你從這 7,776 種組合中精準計算出正確的 Tailwind Class。

## 1. 編寫 tv 非常直觀，它主要由三個部分組成：
base (基礎樣式)：所有狀態下都會套用的通用 Class。
variants (變體對照表)：定義各種屬性（如 color、size）與可選值的 Key-Value 表。
defaultVariants (預設變體)：未傳入參數時的預設值。

```html
<script>
  import { tv } from "tailwind-variants";

  // 用法與 cva 完全相同！
  const button = tv({
    base: "font-semibold rounded", // cva 的第一個參數在 tv 裡面寫作 base
    variants: {
      color: {
        primary: "bg-blue-500 text-white",
        secondary: "bg-gray-500 text-white"
      },
      size: {
        sm: "text-xs px-2 py-1",
        md: "text-sm px-4 py-2"
      }
    },
    defaultVariants: {
      color: "primary",
      size: "md"
    }
  });

  let { color = "primary", size = "md" } = $props();
</script>

<button class={button({ color, size })}>
  按鈕
</button>
```






# 2. 高級進階功能 (tv 比 cva 更強大的地方)

## (1) 跨欄位組合條件 (compoundVariants)
當多個屬性同時滿足特定條件時，要額外追加 Class：

```js
export const buttonVariants = tv({
  base: "...",
  variants: {
    color: { primary: "...", outline: "..." },
    size: { sm: "...", lg: "..." }
  },
  
  // 💡 當 color="outline" 且 size="sm" 時，自動追加 border-2
  compoundVariants: [
    {
      color: "outline",
      size: "sm",
      class: "border-2 font-bold", // 或用 className: "..."
    },
  ],
});
```

## (2) Slots 功能：一次定義「多個子元素」的樣式（極為強大！）
如果你要寫一個複雜元件（如 Card 或 Accordion），tv 允許你在同一個 tv 定義中同時控制外層容器與內層子元素：

💥 沒有 Slots 前：解決「子零件樣式聯動」的痛苦
假設你要製作一個卡片組件 <Card/>，它裡面有 3 個小零件：

外層容器 (container)
標題 (title)
內文 (description)
現在你有一個需求：「當卡片狀態是 status="error" 時，外層邊框要變紅、標題字體要變紅、內文顏色要變淡紅。」

## ❌ 如果不用 Slots（傳統做法）：
你必須在 < script > 裡面寫 3 個獨立的 tv，而且這 3 個 tv 裡面都要重複寫一遍 status 變體邏輯：

```html
<script>
  import { tv } from "tailwind-variants";

  // 1. 容器的 tv
  const containerTv = tv({
    base: "p-4 rounded-lg border bg-white",
    variants: {
      status: {
        normal: "border-gray-200",
        error: "border-red-500 bg-red-50", // 👈 重複 1
      }
    }
  });

  // 2. 標題的 tv
  const titleTv = tv({
    base: "font-bold text-lg",
    variants: {
      status: {
        normal: "text-gray-900",
        error: "text-red-600", // 👈 重複 2
      }
    }
  });

  // 3. 內文的 tv
  const descTv = tv({
    base: "text-sm",
    variants: {
      status: {
        normal: "text-gray-500",
        error: "text-red-400", // 👈 重複 3
      }
    }
  });

  let { status = "normal" } = $props();
</script>

<!-- Markup 中要手動給每一個零件傳一次 status -->
<div class={containerTv({ status })}>
  <h3 class={titleTv({ status })}>錯誤提示</h3>
  <p class={descTv({ status })}>請重新輸入資料</p>
</div>
``` 

使用 Slots 後：一次集中管理所有子零件
Slots 讓你把所有子零件的樣式「打包」在同一個 tv 結構裡面：

```html
<script>
  import { tv } from "tailwind-variants";

  // 用一個 tv 同時定義 3 個子零件 (Slots)！
  const cardTv = tv({
    // 1. 用 slots 宣告這盒積木裡面有哪幾個零件
    // key 就是零件  value 就是 base classs
    slots: {
      container: "p-4 rounded-lg border bg-white",
      title: "font-bold text-lg",
      desc: "text-sm",
    },
    
    // 2. 當 status 改變時，直接在同一個 place 聯動修改多個 slots！
    // 當

    variants: {
      status: {
        normal: {
          container: "border-gray-200",
          title: "text-gray-900",
          desc: "text-gray-500",
        },
        error: {
          container: "border-red-500 bg-red-50",
          title: "text-red-600",
          desc: "text-red-400",
        },
      },
    },
  });

  let { status = "normal" } = $props();

  // 3. 呼叫一次 cardTv({ status })，它會直接傳回所有子零件計算好的 Class 函式！
  const { container, title, desc } = cardTv({ status });
</script>

<!-- Markup 變得很乾淨，而且 status 只需要傳一次！ -->
<div class={container()}>
  <h3 class={title()}>錯誤提示</h3>
  <p class={desc()}>請重新輸入資料</p>
</div>
```
