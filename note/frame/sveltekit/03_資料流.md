# 資料流

1. +page.server.js load() 讀取資料，回傳 object
2. 自動水合 > +page.svelte
3. +page.svelte   let { data } = $props(); 直接取得資料



# 步驟一  在伺服器端抓資料
```js
// src/routes/products/[id]/+page.server.js

export async function load({ params, fetch, platform }) {
  // 1. 取得網址變數
  const productId = params.id; 

  // 2. 向你的 API/Proxy 抓取 Big JSON（完全在 Server/Edge 端進行）
  const res = await fetch(`https://your-proxy.com/api/products/${productId}`);
  const bigJson = await res.json();

  // 3. 直接回傳一個 Plain JavaScript Object
  return {
    product: bigJson,
    fetchedAt: new Date().toISOString()
  };
}
```

參數作用範例用途params網址上的動態變數params.id 拿到 /products/[id] 的 IDfetchSvelteKit 增強版 Fetch具備快求重用、相對路徑支援、Cookie 自動帶入url當前請求的 URL 物件url.searchParams.get('category') 抓取 Query Stringcookies存取與寫入 HTTP Cookiecookies.get('session_id') 做身份驗證platformCloudflare 的原生環境變數platform.env.DB 存取 Cloudflare D1 / KV / R2



# 步驟二：SvelteKit 在背景處理「水合（Hydration）」與數據膠水
load 回傳 JSON 後，SvelteKit 在背景幫你完成三件事：

SSR / SSG 渲染： 直接把回傳的 product 帶入元件，將 HTML 渲染出來。

數據內聯： 把這包 JSON 資料壓縮打包，一併塞進 HTML 內文的腳本標籤中。

免二次 Fetch： 當瀏覽器收到 HTML 載入 JS 時，前端完全不需要再對外發起第二次 HTTP Request，直接拿 HTML 裡現成的 JSON 完成初始化。


# 步驟三：在前端畫面使用資料 (+page.svelte)

在對應的 +page.svelte 頁面中，你不需要寫 fetch、不用寫 onMount，直接接收名為 data 的 prop：

```js
<!-- src/routes/products/[id]/+page.svelte -->
<script>
  // 接收 SvelteKit 自動注入的 data 屬性
  let { data } = $props(); // Svelte 5 Runes 寫法 (Svelte 4 為 export let data;)

  // 快捷變數解構
  let product = $derived(data.product);
</script>

<h1>{product.title}</h1>
<p>抓取時間：{data.fetchedAt}</p>
<img src={product.cover_url} alt={product.title} />
```

## sveltekit 入口

svelte 使用 main.js 掛載 App.svelte

svelte 使用 app.html, +layout.svelte, +page.svelte

src/
├── app.html                  <-- 1. 全站的最外層 HTML 骨架
└── routes/
    ├── +layout.svelte        <-- 2. 全站最頂層的外框 (相當於傳統的 App.svelte)
    └── +page.svelte          <-- 3. 網站首頁 / (相當於傳統的 index.svelte)




``` app.html
<!DOCTYPE html>
<html lang="zh-TW">
  <head>
    <meta charset="utf-8" />
    <link rel="icon" href="%sveltekit.assets%/favicon.png" />
    %sveltekit.head%  <!-- SvelteKit 會在這裡注入各頁面的 <title> 與 <meta> -->
  </head>
  <body data-sveltekit-preload-data="hover">
    <div style="display: contents">%sveltekit.body%</div> <!-- 這裡會注入 Svelte 元件 -->
  </body>
</html>
```


``` +layout.svelte     （全站 App 外框，相當於傳統 App.svelte）
<!-- src/routes/+layout.svelte -->
<script>
  // children 屬性代表當前網址對應的 +page.svelte 內容
  let { children } = $props(); 
</script>

<header>
  <nav>我的全站 Header</nav>
</header>

<main>
  <!-- 這裡會自動渲染各個頁面的 +page.svelte -->
  {@render children()} 
</main>

<footer>我的全站 Footer</footer>
```
