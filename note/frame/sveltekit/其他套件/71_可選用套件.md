# Superforms


SvelteKit Superforms 是專為 SvelteKit Form Actions（表單動作） 設計的表單管理庫。

它的核心目的，是為了徹底解決在全棧 Web 開發中 「重複寫前後端驗證、狀態同步與 UI 互動」 這件繁瑣且極易出錯的粗重工作。

# Embla Carousel

雖然  shadcn-svelte 使用 bits-ui 作為底層，但是高度特化的組件，也能使用業界評分最高的獨立輪播引擎 —— Embla Carousel。

首先確保專案已安裝 shadcn-svelte 的 Carousel，並安裝 Embla 的淡入淡出與自動輪播官方插件：

https://www.embla-carousel.com/docs/examples/predefined
