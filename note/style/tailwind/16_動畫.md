

# svelte vs tailwind動畫
dom 銷毀, if 敘述 時 應採用svelte動畫，其他就交給 tailwind

``` html
<button class="bg-sky-500 hover:bg-sky-600 active:scale-95 text-white font-medium px-5 py-2.5 rounded-xl shadow-md transition-all cursor-pointer">
  點擊我
</button>
```
bg-sky-500 / hover:bg-sky-600：預設天藍色，滑鼠移上去時變深。
active:scale-95：按下去瞬間微微縮放（像真實按鈕的反饋感）。
