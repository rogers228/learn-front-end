

# svelte vs tailwind動畫
dom 銷毀, if 敘述 時 應採用svelte動畫，其他就交給 tailwind

``` html
<button class="bg-sky-500 hover:bg-sky-600 active:scale-95 text-white font-medium px-5 py-2.5 rounded-xl shadow-md transition-all cursor-pointer">
  點擊我
</button>
```

#
bg-sky-500 / hover:bg-sky-600：預設天藍色，滑鼠移上去時變深。
active:scale-95：按下去瞬間微微縮放（像真實按鈕的反饋感）。


# 微互動

觸發狀態(動作變體前綴)
hover:、active:  加上 Transforms 工具  就能讓按鈕、卡片擁有極佳的物理按壓感與反饋。

# 補間
transition-all duration-150   瀏覽器就會以 150 毫秒補間動畫滑順呈現，若無此則為瞬間跳動 不流暢

## 位移
hover:-translate-y-1 位移向上浮起 4px
group-hover:translate-x-1  移動到父元素時 向右位移

## 縮放類（Scale - 凹凸感與聚焦）
active:scale-95：按壓時整體縮小至 95%（按鈕觸感黃金設定）。
hover:scale-105：滑鼠移上去時放大 105%（常用於商品圖片、圖片卡片放大）。
active:scale-90：更強烈的按壓凹陷感（適合 Icon 按鈕或 Like 心形按鈕）。

## 旋轉與斜切類（Rotate & Skew - 生動圖示）
hover:rotate-6 或 hover:-rotate-3：懸停時微微傾斜（適合俏皮風格的卡片、Tag 或圖示）。
group-hover:rotate-12：懸停父容器時，讓內部的 Icon 旋轉。
hover:skew-x-3：產生斜切變形。

## 陰影與外框類（Shadow & Ring - 深度變化）

hover:shadow-lg + active:shadow-inner：懸停時陰影變大（浮起），按壓時變成內陰影（凹陷）。
focus-visible:ring-4 focus-visible:ring-sky-500/30：鍵盤 Tab 選取時產生外發光圈。

## 透明度與濾鏡類
hover:opacity-80 或 hover:brightness-110：懸停時亮度微增或變淡。
hover:blur-none + blur-sm：預設模糊，懸停時變清晰。

##　內建動畫

animate-spin：無窮旋轉（Loading 圈圈）。
animate-ping：波紋擴散（新訊息紅點通知）。
animate-pulse：骨架屏（Skeleton Loader）漸隱漸現。
animate-bounce：上下彈跳（向下滾動引導箭頭）。



## 3D 懸浮抬升卡片（Floating Card）
滑鼠移入時，卡片向上浮起，陰影擴大，且內部圖片自動放大：

``html
<div class="
  group max-w-xs rounded-2xl bg-white p-4 shadow-md border border-slate-100
  transition-all duration-300 ease-out
  hover:-translate-y-2 hover:shadow-xl cursor-pointer
">
  <!-- 圖片容器設定 overflow-hidden 防止圖片溢出 -->
  <div class="overflow-hidden rounded-xl bg-slate-100">
    <img 
      src="https://picsum.photos/300/200" 
      alt="Demo" 
      class="w-full h-40 object-cover transition-transform duration-500 group-hover:scale-110"
    />
  </div>
  <h4 class="mt-3 font-bold text-slate-800">懸浮卡片標題</h4>
  <p class="text-xs text-slate-500 mt-1"> hover 父容器時，圖片會同步平滑放大。</p>
</div>
```
