第二章：核心 Utility Classes 與 CSS 映射
2.1 版面配置（Layout）

Flexbox：flex, inline-flex, items-center, justify-between, gap-*

Grid：grid, grid-cols-12, col-span-*, auto-rows-*

定位與層級：relative, absolute, inset-0, z-*

2.2 尺寸與盒模型（Spacing & Box Model）

間距系統：p-*, px-*, m-*, -m-*（支援負值）

尺寸控制：w-*, h-*, max-w-prose, aspect-square, aspect-video

2.3 色彩與視覺樣式（Colors & Visuals）

OKLCH 色彩空間與 P3 廣色域調色盤（bg-sky-500, text-slate-800）

不透明度修飾符新語法：bg-blue-500/50, text-black/75

圓角、陰影與邊框：rounded-2xl, shadow-md, border, ring-*

2.4 文字排版（Typography）

字型大小、字重與行高：text-sm, font-semibold, leading-tight

文字對齊與截斷：text-center, truncate, line-clamp-3


第三章：響應式設計與狀態變體 (Variants)
3.1 響應式切換（Responsive Design）

移動優先（Mobile-First）原則：block md:flex lg:grid

自訂斷點修飾符與 v4 內建的 Container Queries (@container, @min-md:flex)

3.2 互動與狀態變體（State Variants）

基礎狀態：hover:, focus:, active:, disabled:

表單狀態：focus-visible:, checked:, invalid:

3.3 父子/同級組件關聯變體（Advanced Variants）

group-*：父元素 hover 時改變子元素樣式

peer-*：同級前置元素狀態改變時調整當前元素

has-*：根據子元素狀態調整父元素（CSS :has() 映射）

not-*：反向選擇器 variant

3.4 暗黑模式（Dark Mode）

dark: 修飾符運作機制

搭配 CSS 變數或 class 策略實作主題切換
