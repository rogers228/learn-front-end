# 觸發狀態(動作變體前綴)

在傳統 SCSS 中，處理 Hover 或 Focus 狀態通常需要編寫巢狀選擇器（例如 &:hover 或 &:focus）；處理同層級元素連動時，則必須手動串接通用兄弟選擇器（~）或相鄰兄弟選擇器（+）。

hover:  懸停
focus:  獲得焦點
focus-visible:   僅使用tab獲得焦點
active:   按下

disabled:  停用
checked:   核取按鈕被選取時


# 父元件觸發

當你希望「滑鼠移入父容器時，改變子元素樣式」（例如： hover 一張卡片時，裡面的標題變色、圖示放大），請使用 group 與 group-*

在父容器加上 group class。
在子元素加上 group-hover:*、group-focus:* 或 group-active:*

如果出現「父卡片裡面又有子按鈕」的多層級結構，為了避免內外層混淆，可以使用具名 Group，例如 group/{name}


# 同級元素觸發：peer-* 變體

運作機制
在前置兄弟元素加上 peer class。

在後續兄弟元素加上 peer-* 變體（如 peer-focus:* 或 peer-checked:*

(注意：peer 必須出現在 peer-* 的前面，這符合 CSS 兄弟選擇器的 DOM 順序規則)



# 看子元素條件觸發父元素：has-* 變體（原生 :has() 映射）
以前要根據子元素的狀態去改變父元素，必須依賴 JS。現在直接使用 has-*

```html
<!-- 當裡面的 Radio 被選取 (checked) 時，整個父層 label 邊框變高亮藍色 -->
<label class="flex items-center gap-3 p-4 border rounded-xl has-[:checked]:border-sky-500 has-[:checked]:bg-sky-50/50 cursor-pointer">
  <input type="radio" name="plan" class="accent-sky-500" />
  <span>專業版方案</span>
</label>
```

# 反向狀態選擇器：not-* 變體

```html
<!-- 除了 Hover 狀態之外，保持不透明度 75% -->
<button class="opacity-75 not-hover:scale-95 transition-transform">
  按鈕
</button>
```


# 容器查詢（Container Queries）
傳統 @media 是依據「螢幕寬度」，而 Container Queries 是依據「元件本身的容器寬度」調整排版（非常適合重用元件）：

```
<!-- 1. 將父區域標註為容器 (@container) -->
<div class="@container">
  <!-- 2. 當這個容器寬度大於 320px (@min-md) 時，啟用 Flex 排版 -->
  <div class="flex flex-col @min-md:flex-row gap-4">
    <div class="w-full">內容 A</div>
    <div class="w-full">內容 B</div>
  </div>
</div>
```
