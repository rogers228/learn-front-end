# 距離數值

Tailwind 的預設數值基礎單位是 0.25rem (4px)，代表 數值 × 4px = 實際像素：

p-1 = padding: 0.25rem; (4px)
p-2 = padding: 0.5rem; (8px)
p-4 = padding: 1rem; (16px)
p-6 = padding: 1.5rem; (24px)
p-8 = padding: 2rem; (32px)

px-4（左右 Padding: pl-* + pr-*）

py-2（上下 Padding: pt-* + pb-*）

負數
-mt-4（margin-top: -1rem;）
-mb-4 (margin-bottom: -1rem; )


# 寬高

固定尺寸：w-64 (16rem / 256px), h-12 (3rem / 48px)

相對/比例：w-full (100%), w-screen (100vw), h-dvh (動態 Viewport 高度，解決行動端 Safari 導覽列問題)

邊界限制：
max-w-md (max-width: 28rem; ),
max-w-7xl (max-width: 80rem; ), 
min-h-screen (min-height: 100vh; )

長寬比（Aspect Ratio）：aspect-video (16:9), aspect-square (1:1)
