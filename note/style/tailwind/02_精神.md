

# 原子化

不再為元件命名，而是直接在tag標籤上組合單一職責的樣式，

flex items-center justify-between p-4 bg-white rounded-xl shadow-md。


# sveltekit 

[ vite.config.ts ] ──> 啟動 @tailwindcss/vite 插件，即時掃描全專案 Class
        │
[ src/routes/layout.css ]   ──> 定義 @import "tailwindcss"; 作為 CSS 樣式根源
        │
[ src/routes/+layout.svelte ]──> 引入 layout.css，將樣式分發至 SvelteKit 所有頁面與元件



# rem

全面使用 rem，放棄 px 單位 因為裝置會有縮放，不能寫死

1 rem = 16px

# tailwind 單位

1 = 0.25 rem = 4px
2 = 0.5 rem  = 8px
3 = 0.75 rem = 12px
4 = 1 rem = 16px

p-4 > padding: 1rem;
