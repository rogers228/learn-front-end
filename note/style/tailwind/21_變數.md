# 變數  直接寫在入口檔 layout.css

## 入口檔
名稱自訂，layout.css   app.css
在 sveltekit 由  routes/+layout.svelte  引入入口檔 css


## 定義變數

變數名稱以 --開頭

``` css

@import "tailwindcss";

@theme {
  /* 1. 自訂色彩（擴充/覆蓋） */
  --color-brand: #0066ff;
  --color-brand-hover: #0052cc;
  --color-accent: oklch(0.7 0.25 140); /* 支援現代 OKLCH 色彩格式 */

  /* 2. 自訂字型家族 */
  --font-display: "Inter", system-ui, sans-serif;
  --font-code: "Fira Code", monospace;

  /* 3. 自訂邊界斷點 (Breakpoint) */
  --breakpoint-3xl: 120rem; /* 1920px */

  /* 4. 自訂動態動畫 (Keyframes + Animation) */
  --animate-fade-in: fade-in 0.3s ease-out;

  @keyframes fade-in {
    0% { opacity: 0; transform: translateY(10px); }
    100% { opacity: 1; transform: translateY(0); }
  }
}
```


## 特殊變數

--color-brand > 自動生成 bg-brand、text-brand、border-brand、ring-brand。
--font-display> 自動生成 font-display。
--breakpoint-3xl > 自動生成 3xl: 響應式前綴修飾符。
--animate-fade-in > 自動生成 animate-fade-in。

## 讀取 css變數

``` html
<!-- 自動解析 CSS 變數 var(--user-theme-color) -->
<div class="bg-(--user-theme-color) text-(--user-text-color)">
  動態主題區塊
</div>
```

# 權重

權重低 ───────────────────────────────────────────► 權重高
@layer theme ──► @layer base ──► @layer components ──► @layer utilities

utilities > components > base > theme

## 使用 @layer  設定權重在最外層

@layer base {
  body {
    background-color: var(--color-slate-900);
    color: var(--color-slate-100);
    font-family: var(--font-display);
  }
  
  h1 {
    font-size: var(--text-3xl);
    font-weight: bold;
  }
}

## 自訂 @layer utilities
如果預設的 Utility 不夠用，你可以手動新增自訂 Class，且確保它的權重高於 Base：

```
@layer utilities {
  /* 新增一個自訂修飾：強制開啟硬體加速 */
  .gpu-accelerated {
    transform: translateZ(0);
    will-change: transform;
  }
}
```
