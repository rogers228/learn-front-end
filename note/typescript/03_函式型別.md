# 函式型別 (Functions)

嚴格定義函數的輸入型別、輸出型別

```ts

// 1. 先定義好 User 物件應該長怎樣
interface User {
  id: string;
  name: string;
  email?: string;
}

// 2.定義參數型別與回傳型別 (: Promise<User>)
async function fetchUser(id: string): Promise<User> {
  const res = await fetch(`/api/user/${id}`);
  return res.json();
}

// 3. 實際呼叫使用
const user = await fetchUser('123');

```


1. 限制 id 為 string 型別
2. 在 JavaScript 中，只要函式前面加上 async，它一定會回傳一個 Promise（非同步物件）。它是一個容器，必須指定裡面型別為 User 結構的物件
