

# 第一防線：編輯時（Editor  IDE Time）

即時紅線警告（Linter Warning）：

當你拼錯字（如 data.user.namme），不用等存檔，輸入完的下一毫秒紅線就劃下去了。

極致的自動補全（IntelliSense）：

按下 . 的瞬間，直接選單跳出所有合法的屬性與方法，連文件都不用查。

安全重構（Refactoring）：

在變數或屬性上按 F2 改名，全專案幾十個檔案會自動同步修改；如果改漏了或有衝突，編輯器立刻紅字提醒。

型別 Hover 預覽：

滑鼠移到任何變數上，立刻顯示它「現在是什麼型別」、「可能包含哪些欄位」。

# 第二防線：儲存與開發時（Save / Dev Server Time）—— 門衛擋路

當你寫完程式碼按下 Ctrl + S，SvelteKit 的開發伺服器（Dev Server）與 Vite 開始運作。

核心體驗：
Terminal 終端機報錯：

即使你無視了 IDE 的紅線硬要存檔，Terminal 會立刻印出鮮紅色的 ErrorLog，並精準指出是哪一行程式碼型別不符。

瀏覽器 Overlay 覆蓋畫面：

畫面不會默默呈現壞掉的狀態，而是直接跳出全螢幕的 Error Overlay，強制你先修正型別問題才能繼續預覽。


# 第三防線：打包與 CI/CD 編譯時（Build / Compile Time）—— 最終安全閘門 🔒
當你準備將 SvelteKit 專案部署上線，執行 npm run build 時。

# 第四防線：執行期（Runtime）—— ⚠️ 注意：TS 的保護邊界！

TypeScript 在經過 Build 之後，所有的型別標註（type, interface, : string）都會被完全剝離（Strip），最後跑在瀏覽器與 Node.js 上的只有純 JavaScript。
