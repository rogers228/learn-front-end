# 核心型別與宣告

加上 `: string` 

```ts

let name: string = 'SvelteKit';
let age: number = 2026;
let isAwesome: boolean = true;
let tags: string[] = ['svelte', 'typescript']; // 字串陣列


let score = 100; // TS 自動推導 score 為 number
```



## any 與 unknown (型別逃生門 vs. 安全驗證):

any: 放棄型別檢查（儘量少用，不然就白寫 TS 了）。
unknown: 不確定是什麼型別，使用前必須先檢查（較安全）



## 聯合型別 (Union Types):
使用 ` | ` 代表 or 限制在裡面

type Status = 'pending' | 'success' | 'error'; // 只能是這三個字串之一
let currentStatus: Status = 'success';
